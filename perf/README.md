# perf/

Machine-readable measurements used by `docs/PERFORMANCE.md`.

| File | What it is |
|---|---|
| `baseline.json` | `out/` measurement of the commit **before** the optimization pass (`d07bbdb`), built unmodified. |
| `final.json` | `out/` measurement after the pass (default for `perf:compare`). |
| `after-mermaid.json`, `after-bundle.json`, `after-deadpaths.json`, `after-minify.json` | Intermediate checkpoints taken while applying each build change, kept so the effect of each step can be audited. |
| `snapshots/` | Scratch diffs; safe to delete. |

Generated by:

```bash
node scripts/perf-report.mjs --save perf/<name>.json
node scripts/perf-compare.mjs perf/baseline.json perf/final.json
```

The JSON schema is stable: `renderer.{bytes,files,js.{bytes,gzip},assets}`,
`main`, `preload`, `totalOut`, `critical.{files,bytes,gzip,entryBytes,appBytes}`,
`css.{bytes,gzip}`, `fonts.{count,ttf,woff,woff2,total}` and `largestChunks`.

V8 parse/compile and retained-heap numbers are not in these files because they
depend on the engine build; record them in `docs/PERFORMANCE.md` from
`scripts/measure-bundle.cjs`.
